# Experimental builds (not the official final release)

The `ERINX_Smart_Hub_V5_2/` snapshot adds a Wi-Fi browser-based file manager. It is kept for future development and reproducibility, **not** as the official submission.

- The official final sketch is [V5.1.3](../final/ERINX_Smart_Hub_V5_1_3_UI_Controls/).
- V5.2 consists of the matching `.ino`, `PageTypes.h`, `FileManager.h`, and `FilePortal.h` files. Keep all together when building it separately.
- Localhost on a laptop is not the same as the ESP32 IP address; V5.2's local server was tested separately from the V5.1.3 project scope.
- More details: [V5.2 release notes](../../docs/releases/V5.2.md).
